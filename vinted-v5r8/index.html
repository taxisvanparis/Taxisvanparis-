Pour écrire les annonces, l'appli utilise l'IA gratuite de Google (Gemini). Il faut une clé gratuite, une seule fois :

  1. Ouvre aistudio.google.com/apikey avec ton compte Google.
  2. Appuie sur Create API key, puis copie la clé.
  3. Colle-la ici. Elle reste uniquement sur ton téléphone.
